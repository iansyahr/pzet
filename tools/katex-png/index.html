Tips hasil maksimal

  • Gunakan skala 200-300% agar tajam di dokumen, slide, dan cetakan.
  • Aktifkan latar transparan + tinta gelap untuk ditempel di mana saja.
  • Tambahkan padding 12-24 px agar rumus tidak terpotong saat di-crop.
Bantuan dan pintasan keyboard

Esc - Bersihkan editor (saat fokus di editor)
Ctrl + J - Ganti tema terang/gelap
Ctrl + S - Unduh PNG (jika sudah ada hasil)
